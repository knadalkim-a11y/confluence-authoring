# Recipe: Tutorial / Concept Guide

Use when the reader needs to learn a concept or procedure.

## Suggested structure
1. What the reader will understand
2. Minimal prerequisites
3. Core idea
4. Step-by-step explanation
5. Worked example
6. Common mistakes
7. Summary / next step

## Visual guidance
Progressive reveal can help when later concepts depend on earlier ones. Keep the final state visible so the page remains useful as reference material.
