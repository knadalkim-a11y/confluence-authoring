# Recipe: Comparison

Use for current vs proposed, option A vs B, or behavior before/after a change.

## Suggested structure
1. Comparison question
2. Shared evaluation dimensions
3. Side-by-side comparison
4. Important tradeoffs
5. What is factually different
6. Decision status, if a decision has actually been made

## Visual guidance (spec kinds: `references/visual-specs.md`)
Use a table for stable dimensions. `bars` (paired) for one measure in one unit; two `diagram`s
(current / proposed) for structural options; `flow` with two variants when the difference is
capacity or queueing. Motion only if the difference is a process or time-dependent behaviour.

## Rule
Do not manufacture a winner when the source does not establish one.
