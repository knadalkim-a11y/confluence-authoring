# Recipe: Project Status

Use when the primary question is "Where are we now?"

## Suggested structure
1. Current state
2. Scope and milestone summary
3. Completed since last checkpoint
4. In progress
5. Blocked / risks
6. Decisions needed
7. Next actions

## Good visuals
- milestone timeline
- status table
- workflow motion only when progress through stages matters

## Avoid
- pretending every activity has a numeric percent;
- hiding blockers inside long prose;
- mixing future plan into completed results.
