# Recipe: Implementation Handoff

Use when another developer or agent must execute the work.

## Suggested structure
1. Objective
2. Repository / target / baseline
3. Preserve these existing behaviors
4. Exact implementation scope
5. Contracts and constraints
6. Files / components likely involved
7. Validation cases
8. Required documentation updates
9. Delivery requirements: commit, push, PR, deployment boundary
10. Stop conditions / prohibited changes

## Rule
Write executable instructions, not only design commentary. Explicitly distinguish required implementation from future ideas.
